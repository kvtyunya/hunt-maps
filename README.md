# Hunt Maps — интерактивная карта лута для Hunt: Showdown 1896

Бесплатное offline-приложение для Android: четыре игровые локации, на каждой —
метки лута (всего 8 типов, больше 1100 точек), названия усадеб и фотографии
мест. Метки включаются и выключаются фильтром.

Работает полностью без интернета. Все данные лежат прямо в приложении —
никаких аккаунтов, рекламы и лишних разрешений.

## Скачать

Готовый APK лежит в разделе [Releases](https://github.com/kvtyunya/hunt-maps/releases):
скачайте файл APK из последнего релиза, откройте его на телефоне и разрешите
установку — приложение не из Google Play, поэтому Android попросит подтвердить
установку вручную, это нормально.

## Что уже работает

1. **Выбор карты** — вертикальный список из 4 карт (Стилуотер, Лоусон,
   Маммона, Де-Салль).
2. **Экран карты** — картинку можно двигать пальцем и приближать щипком (до 10x),
   поверх карты — метки лута. Тап по метке показывает подпись и, если есть,
   фото места.
3. **Фильтр** — панель выезжает справа: у каждого типа свой значок и
   переключатель. Есть кнопки «включить все / скрыть все».
4. **Легенда** — экран с расшифровкой всех типов меток.
5. **Названия локаций** — подписи на карте, проявляются при приближении
   (кнопка-тег в верхней панели включает и выключает их).
6. **О приложении** — версия, обратная связь и поддержка разработчика
   (сердечко на главном экране).

Стиль — тёмная «болотная» тема в духе игры: почти чёрный фон, тёплый
костяной текст, акцент — старое золото. Заголовки набраны антиквой.

Ниже — документация для тех, кто хочет собрать приложение сам
или завести свои карты и точки.

## Как запустить

Тебе понадобится **Android Studio** (бесплатная, с сайта developer.android.com).
Дальше:

1. Открой Android Studio → **Open** → выбери папку `D:\Projects\maphunt`.
2. Подожди, пока студия скачает недостающие компоненты (она предложит это сама,
   нужен интернет только один раз — при первой сборке).
3. Подключи телефон по USB (в настройках телефона включи «Отладка по USB»)
   или создай эмулятор (Device Manager → Create Device).
4. Нажми зелёную кнопку **Run** ▶ — приложение установится и откроется.

Если студия при открытии спросит про обновление Gradle — соглашайся.

## Как добавить свои карты (картинки)

1. Положи свои картинки в папку
   `app/src/main/res/drawable-nodpi/`
   под именами (латиницей, маленькими буквами, без пробелов):
   - `map_stillwater.webp`
   - `map_lawson.webp`
   - `map_mammon.webp`
   - `map_desalle.webp`
2. Всё. Приложение само подхватит новые картинки: и на экране карты,
   и на карточках выбора. Соотношение сторон тоже определится само.

Советы по картинкам:
- WebP (PNG тоже подойдёт), до 4096×4096 px (чем больше — тем тяжелее файл приложения).
- Тёмные карты будут смотреться гармоничнее всего.

## Как расставить точки лута

Все точки лежат в одном файле:
`app/src/main/java/com/huntmaps/data/MapData.kt` — он подробно закомментирован.

Координаты записываются **долями**, а не пикселями:

```kotlin
LootPoint(LootType.SAFES, x = 0.62f, y = 0.30f, note = "Большой дом")
```

- `x = 0.0` — левый край карты, `x = 1.0` — правый край;
- `y = 0.0` — верх карты, `y = 1.0` — низ.

### Вручную

1. Открой картинку карты в любом редакторе (хотя бы в Paint).
2. Наведись на место точки и посмотри её пиксели, например `(1120, 480)`.
3. Раздели их на размер картинки. Для картинки 1920×1920:
   `x = 1120 / 1920 ≈ 0.58`, `y = 480 / 1920 ≈ 0.25`.
4. Запиши в файл: `LootPoint(LootType.CASH_REGISTERS, 0.58f, 0.25f, "Магазин")`.

Не забывай `f` после числа — это «дробное число» для Kotlin.

## Фотографии у точек (где именно находится касса)

У любой точки можно прикрепить фото места: нажмёшь на маркер — внизу
экрана появится карточка с фотографией, тап по ней откроет фото на весь экран.

1. Положи фото в папку `app/src/main/assets/photos/`
   (имя латиницей, например `mammon_bank_1.webp`).
2. У нужной точки в `MapData.kt` допиши параметр `photo`:

```kotlin
LootPoint(LootType.CASH_REGISTERS, 0.6070f, 0.1668f, photo = "mammon_bank_1.webp"),
```

3. Пересобери приложение — готово.

Советы: лучше всего смотрятся скриншоты из игры (16:9); если фото много,
складывай их в подпапки (`photos/mammon/…`) и указывай путь в параметре:
`photo = "mammon/bank_1.webp"`.

## Как менять типы лута

Файл `app/src/main/java/com/huntmaps/data/LootType.kt`.

Каждый тип — это блок:

```kotlin
WORKBENCHES(
    label = "Верстаки",            // название в фильтре и легенде
    description = "Описание…",     // текст в легенде
    color = Color(0xFF7FA8C9),     // цвет маркера
    icon = Icons.Outlined.Handyman // иконка (набор Material Icons)
),
```

Добавишь новый блок — тип появится во всех экранах автоматически
(фильтр, легенда, маркеры). Иконки можно выбирать из бесплатного набора
[Material Symbols](https://fonts.google.com/icons) — в поиске набери слово,
например `safe` или `medkit`, и используй английское имя с большой буквы.

## Названия локаций (подписи на карте)

На карте можно показывать названия усадеб — «Ферма Элис», «Порт Рикер»
и так далее. Кнопка-тег в верхней панели показывает и скрывает все
подписи сразу, а сами названия проявляются, когда приближаешь карту,
и при зуме не растут.

Названия хранятся в `app/src/main/java/com/huntmaps/data/MapData.kt`,
внутри нужной карты, списком `locations`:

```kotlin
GameMap(
    id = "stillwater",
    // …
    locations = listOf(
        MapLocation("Ферма Элис", x = 0.59f, y = 0.40f),
        MapLocation("Порт Рикер", x = 0.65f, y = 0.20f)
    ),
    points = listOf(…)
)
```

x и y — те же доли от 0 до 1, что и у точек лута (0.0 — левый/верхний
край, 1.0 — правый/нижний). Координаты можно снять со скриншота карты
с подписями: доля = пиксель ÷ ширина картинки в пикселях.

Проверить, куда лягут подписи, можно скриптом `py tools\loc_check.py` —
он рисует красные кольца в заданных координатах прямо на картинке карты
и сохраняет результат в `tools\loc_check.png`. Список координат и путь
к карте правятся в начале скрипта — так его можно использовать и для
остальных карт.

## Где что лежит

```
app/src/main/java/com/huntmaps/
├── MainActivity.kt          — точка входа (не трогай)
├── data/
│   ├── LootType.kt          — типы лута: иконки, цвета, описания
│   ├── GameMap.kt           — схема данных (карта и точка)
│   └── MapData.kt           — ТВОИ карты и точки ★ редактируй здесь
├── ui/
│   ├── HuntMapsApp.kt       — навигация между экранами
│   ├── theme/               — тёмная тема: цвета и шрифты
│   ├── home/HomeScreen.kt   — экран 1: выбор карты
│   ├── map/MapViewScreen.kt — экран 2: карта с зумом и маркерами
│   ├── map/FilterPanel.kt   — экран 3: панель фильтра
│   └── legend/LegendScreen.kt — экран 4: легенда
└── res/
    ├── drawable-nodpi/      — картинки карт ★ клади свои сюда
    └── values/strings.xml   — название приложения под иконкой
```

## Мелочи, которые можно настроить за минуту

- **Название приложения**: `app/src/main/res/values/strings.xml` → `app_name`.
- **Цвета темы**: `ui/theme/Color.kt` — все цвета подписаны по-русски.
- **Максимальный зум**: `ui/map/MapViewScreen.kt`, константа `MAX_ZOOM`.

## Если что-то не работает

- **«Sync failed» при открытии** — проверь интернет и нажми File → Sync
  Project with Gradle Files.
- **Точка не на месте** — проверь, что не перепутаны местами x и y
  и что числа записаны с `f` на конце (`0.5f`, а не `0.5`).
- **Заменила картинку, а в приложении старая** — нажми Run ещё раз:
  картинка «вшивается» в приложение при сборке.
